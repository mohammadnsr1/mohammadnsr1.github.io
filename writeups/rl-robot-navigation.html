RL and Optimization · Q-Learning Navigation

Application of Reinforcement Learning in Robot Navigation

Q-learning for shortest path navigation, connected back to the numerical optimization methods behind it.

  • Course
    Reinforcement Learning Specialization, Coursera, based on Sutton and Barto
  • Role
    Algorithm implementation, testing, and connecting theory back to optimization
  • Environment
    OpenAI Gym, Cliff Walking grid world
  • Stack
    Q-learning, epsilon greedy exploration, exploration decay
    • Repository Reinforcement Learning Specialization, Coursera

    Mission

    Given a starting position and a target position, how does a robot find the shortest path between them without being told the answer directly. Reinforcement learning offers one answer: an agent that learns through trial and error, taking actions, observing rewards, and gradually discovering which behavior leads to the best long term outcome, rather than following labeled examples the way supervised learning does.

    This project works through the underlying theory first, Markov decision processes, the Bellman equation, and policy evaluation and improvement, then implements the Q-learning algorithm and tests it in a navigation setting. The Q-learning implementation and the surrounding theory follow a Reinforcement Learning Specialization completed on Coursera, based on the Sutton and Barto reinforcement learning textbook.

    Method

    Q-learning is a sample based method, meaning it needs no prior model of how the environment behaves, it learns purely from experience. At each state the agent follows an epsilon greedy policy, mostly choosing its current best known action but occasionally exploring a random one, then updates its estimate of that action's value based on the reward received and the value of the resulting state.

    Repeating this cycle across many episodes causes the agent's value estimates to converge toward the true optimal policy, without ever being told what that policy is in advance.

    Test environment and results

    The method was tested on the Cliff Walking environment from OpenAI Gym, a grid world where the agent starts at one corner and must reach a goal at the opposite corner, with a strip of cells along the bottom acting as a cliff. Falling off the cliff carries a large penalty and resets the agent to the start, while every other move carries a small penalty, which pushes the agent toward the shortest safe route rather than a longer, safer detour.

    With a fixed exploration rate, the agent reliably learned the optimal path that hugs the cliff edge, but its episode rewards kept oscillating, since random exploratory moves occasionally sent it over the edge even after it already knew better.

    Adding exploration decay, so the agent explores less as it gains more experience, sharply reduced that oscillation and pushed the agent toward a fully deterministic optimal policy. The agent was not wrong about the best path early on, it just kept testing the drop out of habit until exploration itself was reined in.

    Connecting back to optimization

    A core part of this project was recognizing how much reinforcement learning shares with the numerical optimization methods studied earlier in the same coursework. Policy iteration in RL mirrors iterative methods like steepest descent and Newton's method: an initial guess, here a policy, is progressively refined rather than solved in one step.

    The reward function plays a role similar to penalty and barrier methods in constrained optimization, shaping the objective by penalizing undesirable outcomes, here falling off the cliff, rather than being optimized directly itself. The learning rate in Q-learning plays a role similar to step size selection in backtracking line search, controlling how large an update is applied at each step so learning is substantial without overshooting.
